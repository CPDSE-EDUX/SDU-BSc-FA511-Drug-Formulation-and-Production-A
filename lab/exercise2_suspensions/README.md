# Lab exercise 2: suspensions

Students study how different excipients affect the sedimentation and redispersibility of sulfur suspensions (A to E). In the exercise class the week after the lab, they plot their results in R and set up a full report in Quarto. The guide shows three types of plot: sediment volume over time for suspension A (point-line), stacked bar charts of sediment, turbid and clear supernatant over time for suspension B (the same plot can be made for C to E), and a bar chart comparing the final sediment volumes.

## Files

| File | Description |
|------|-------------|
| `FA511_databehandling_suspensioner.html` | Rendered guide, open in a browser (Danish) |
| `FA511_databehandling_suspensioner.qmd` | Quarto version of the guide |

The data are entered directly as data frames in the guide, so no data files are needed.
