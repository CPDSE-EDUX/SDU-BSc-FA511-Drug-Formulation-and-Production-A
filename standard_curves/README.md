# Exercise class: standard curves

Students plot UV absorbance standard curves for the three drugs used in lab exercise 1 (paracetamol, sulfadiazine and ibuprofen). The guide uses ibuprofen as the example: enter triplicate dilution series as a data frame, calculate mean and standard deviation, fit a linear regression with `lm()`, and plot the curve with error bars, regression line, equation and R² in ggplot2.
