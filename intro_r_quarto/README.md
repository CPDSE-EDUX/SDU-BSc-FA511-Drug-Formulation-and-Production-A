# Exercise class: acid/base functions and Quarto

Problem-solving class (e-time) where students meet R and Quarto for the first time in the course. Students write short R functions for the degree of ionisation of weak acids and bases (Henderson-Hasselbalch), plot Bjerrum diagrams, and set up a Quarto document with text, code and an image. They then calculate the degree of ionisation of naproxen and zolmitriptan at pH 2, 5 and 7.4 and plot their Bjerrum diagrams.
